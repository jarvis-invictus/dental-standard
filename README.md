# Dental Standard — White-Label Dental Clinic Website Template

A fully white-label, production-ready dental clinic website.

## Quick Start

```bash
git clone https://github.com/jarvis-invictus/dental-standard.git my-clinic
cd my-clinic
npm install
npm run dev
```
